##  Project Details


* **[project_unity](./project_unity):** A 3D survival horror zombie horde game built in Unity in 2015 as my 12th grade PAP final project (TGPSI), graded 20/20. Features A\* pathfinding enemies, volumetric sky and fog, weapon swap and sway, head bob, jump scares and enemy spawning.

* **[basic_detailing](./basic_detailing):** A responsive single-page landing site for Dream Detailing UK, with a hero slider, image gallery, team section and a contact form with an emoji satisfaction slider.
* **[webm_viewer](./webm_viewer):** A single-file HTML page that plays up to 9 random WebM clips at once in a grid, with an optional 10-second automatic rotation. It runs fully local in the browser.
* **[php_report](./php_report):** A legacy PHP mission report generator and viewer backed by MySQL, showing events, orders and messages per user. It uses the deprecated `mysql_*` extension, so it only runs on PHP 5.x.

* **[GoogleBGChanger](./GoogleBGChanger):** A Chrome extension (Manifest V3) that changes the background color of Google's dark mode to `#252527`.

* **[windows_bug_policies](./windows_bug_policies):** A batch script that fixes the "Some settings are managed by your organization" message in Windows 10 by resetting local group policies and policy registry keys.

* **[c_exercises](./c_exercises):** A set of C programs and mini-projects from my programming course, covering control structures, arrays, strings, `struct` and basic game logic (including a console Minesweeper).

## How to Use

### 1. Get the Repository
Clone it to your machine:

    git clone <your-repo-url>
    cd <your-repo-folder>

### 2. Pick a Project
Open the folder of the project you want:

    cd webm_viewer

### 3. Follow Its README
Each folder has its own instructions for building or running it.
