# C Programming Course Exercises

A collection of C programs, practice exercises, and mini-projects developed as part of a programming course.

The repository covers fundamental concepts such as control structures, arrays, strings, structures (`struct`), and basic logic.

> Note: Each file is a standalone program with its own `main`, so every exercise is compiled and run on its own.
---

##  Exercises Overview

### Technical Specifications
* **Language:** C.
* **Compiler:** `gcc` (or any standard C compiler).
* **Concepts Covered:** Control structures, arrays, strings, `struct`, and basic game logic.
* **Structure:** One `.c` file per exercise, no external dependencies.

---

##  Exercises

### Math & Conversions
* **`calculator.c`:** A basic command-line arithmetic calculator.
* **`can_volume.c`:** Calculates the geometric volume of a cylindrical can.
* **`currency_converter.c`:** Converts values between different currencies.
* **`double_triple_square.c`:** Computes the double, triple, and square of given numbers.

### Arrays & Vectors
* **`adult_minor_array.c`:** Categorizes and stores ages in an array to separate adults and minors.
* **`count_adults_minors.c`:** Counts the quantity of adults and minors from a set of inputs.
* **`vector_intersection.c`:** Finds the intersection elements between arrays/vectors.

### Strings
* **`count_char_in_string.c`:** Counts the occurrences of a specific character in a string.
* **`palindrome.c`:** Checks if a given word or sequence reads the same forwards and backwards.

### Conditions & Menus
* **`customer_type.c`:** Classifies customers based on predefined conditions/rules.
* **`menu_even_positive.c`:** An interactive menu program validating even and positive numbers.
* **`swimmer_prize.c`:** Evaluates swimmer times or scores to assign prizes/placings.
* **`star_rectangle.c`:** Prints geometric shapes and rectangles using asterisks (`*`).

### Structures
* **`library_books.c`:** Manages book records and inventory using structures.
* **`structs_cars.c`:** Demonstrates the use of C `struct` to manage and organize car data.

### Games & Simulations
* **`dragon_vault.c`:** A text-based mini-game or interactive puzzle challenge.
* **`euromillions.c`:** Generates or simulates EuroMillions lottery number combinations.
* **`minesweeper.c`:** A console-based implementation of the classic Minesweeper game.

## Installation & Build Steps

### 1. System Prerequisites
Make sure you have a C compiler installed. On Debian/Ubuntu:

    sudo apt-get install gcc

### 2. Compile an Exercise
Replace `filename.c` with the program you want to run (e.g., `calculator.c`):

    gcc filename.c -o program

### 3. Run It
Execute the compiled program:

    ./program
