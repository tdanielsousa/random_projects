# Detailing Services — Landing Page

A responsive, interactive single-page website built for **Dream Detailing**, showcasing automotive detailing services, team members, a dynamic photo gallery, and an interactive customer satisfaction contact form.

Everything is plain HTML, CSS and vanilla JavaScript, with no build tools or dependencies.

> Note: This project was developed under strict layout and structural requirements—showcasing a custom hero slider, CSS Flexbox/Grid layouts, responsive design, and pure Vanilla JavaScript for dynamic DOM manipulation and interactive components.
---

##  Page Architecture & Design

The site is a single page split into clearly separated sections, each styled and scripted independently.

### Technical Specifications
* **HTML5:** Semantic layout (`<header>`, `<main>`, `<section>`, `<footer>`) and accessible form controls.
* **CSS3:** Flexbox and Grid layouts with responsive styling and animations.
* **JavaScript (Vanilla):** DOM manipulation for the hero carousel and the live range-slider-to-emoji feedback.
* **Responsive:** The layout adapts from desktop to mobile, including the multi-column gallery.

---

##  Page Sections

### 1. Hero Banner Slider (`#main_banner`)
Full-width image slideshow showcasing various detailing stages and results.

### 2. About / Split Layout (`.split_layout`)
Side-by-side introduction highlighting paint correction, protection, and mobile detailing expertise.

### 3. Services Band (`.full_band`)
Full-width highlight section detailing the core offerings: *Detailed Wash* and *Ceramic Coating*.

### 4. Responsive Image Gallery (`.gallery_section`)
Multi-column responsive grid displaying portfolio shots.

### 5. Team Showcase (`.team_container`)
Circular staff profile cards introducing the detailing specialists.

### 6. Contact & CSAT Form (`.form_section`)
Contact form with validation and a synchronized **1 to 5 emoji satisfaction range slider** (`#satisfaction_slider`).

---

##  Project Structure

* **`index.html`:** Semantic HTML5 structure and page sections.
* **`style.css`:** Layout styling, responsive grids, and animations.
* **`script.js`:** Banner slider logic and interactive emoji rating controls.

## Installation & Run Steps

### 1. Get the Files
Clone or download the repository:

    git clone <your-repo-url>
    cd <your-repo-folder>

### 2. Open the Page
No build tools or dependencies are required. Open `index.html` directly in any modern browser (Chrome, Firefox, Edge, Safari), or use an extension like Live Server in VS Code.
